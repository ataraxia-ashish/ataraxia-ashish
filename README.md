## Products

### 🔍 Real vs AI Image Detector
> *Can you trust what you see? This tool can tell.*

In a world where AI-generated images are indistinguishable from real ones — even to experts — this tool gives you a definitive answer in seconds.

- **What it does:** Detects whether any image is real or AI-generated with high confidence
- **Result:** 83.57% accuracy · F1 Score 0.84 · Tested on 3,000 unseen images
- **Confidence:** Flagged an advanced AI image at **99.86% confidence as FAKE**
- **Tech:** Python · TensorFlow · EfficientNetB3 · Transfer Learning · MS COCO Dataset

[![View Repo](https://img.shields.io/badge/View%20Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ataraxia-ashish/Real-VS-Ai-Image-Detector)
